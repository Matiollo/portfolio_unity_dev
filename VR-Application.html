VR Application

NDA

This project is under NDA, so I can describe how it was built but can't say much about the product itself. It's a Unity VR application that connects to our custom server over gRPC and receives a video stream from a separate OvenMediaEngine (OME) server. I was solely responsible for building the application, while my colleagues set up the servers and other parts of the system that were outside the Unity application's scope.

Some of the things I worked on

gRPC

The application had to communicate with one of the servers over gRPC, which turned out to be an interesting task. Unity was restricted to HTTP/1, and I could find very few gRPC implementations for Unity that worked within that limitation. On top of that, some of the setups I tried worked in the editor but couldn't be built to run on the headset.

Custom video player

To receive the video stream from the OME server, I first tried several existing WebSocket libraries for Unity. None of them worked, so I ended up using the standard WebSockets and writing a custom video player. It emulated the behavior of the OME test webpage to receive frames from the server, then rendered them on the inside of a sphere to create a 360° video effect.

The whole application

I was the only developer on this application, so beyond the server integrations, I was responsible for its architecture, UI, testing, documentation and everything else. It was a bit stressful, but it definitely helped me grow as a developer.
